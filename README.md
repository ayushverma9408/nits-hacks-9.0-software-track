# E.D.I.T.H.

**Enhanced Digital Identity, Trust & Heuristics** — a hackathon prototype for visibility and control over connected-app access.

## Run locally

```bash
npm install
npm run dev
```

## Prototype features

- Identity overview with a dynamic trust score
- Connected-app access and permission controls
- Activity timeline with simulated anomaly signals
- Revoke / restrict controls and a local audit history
- Explainable recommendations

> This is a demonstration prototype. Activity, risk signals, and connected services are simulated locally; it does not connect to real accounts or revoke real-world permissions.

## Stack

React, Vite, and plain CSS.
